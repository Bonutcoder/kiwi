System Architecture & Data Flow

```
The SentinelNet architecture operates strictly over a Local Area Network (LAN)
generated by the ESP32. It does not require internet access to perform the
cryptographic verification.
```

Development Roadmap
Phase 1: Cryptographic Foundation (Hours 1 - 4)
Generate Static Keys: Member 1 writes a temporary script to generate an Ed25519
key pair. Hardcode the 32-byte Private Key in the ESP32 C++ sketch and pass the
32-byte Public Key to Member 2.
```

```
Hardware Test: Member 1 flashes the ESP32 to simply read a hardcoded string,
sign it, and print the 64-byte signature to the Serial Monitor.
```

```
Software Test: Member 2 writes a pure Dart script (no UI) to take that exact
hardcoded string and the 64-byte Serial Monitor signature, and verify it returns
true.
```

```
Phase 2: Network & API Bridging (Hours 4 - 10)
Access Point Setup: Member 1 configures the ESP32 to act as a Wi-Fi Access Point
(WiFi.softAP()) and initializes an asynchronous WebServer on port 80.
```

```
API Endpoint: Member 1 creates a /verify endpoint that accepts POST requests
containing the nonce string, signs it, and returns the 64-byte signature as a
JSON array.
```

```
App Integration: Member 3 links the "Connect" button in the Flutter UI to
trigger Member 2's verification logic over the local HTTP connection.
```

Immediate Next Steps to Start Developing
```

```
Initialize the Repositories: Set up a GitHub repository containing two root
folders: /firmware (for the Arduino sketch) and /mobile_app (for the Flutter
project).
```

```
Install Cryptography Dependencies:
```

```
Arduino IDE: Go to Library Manager and install Crypto by Rhys Weatherley
(Southern_Storm_Crypto).
```

```
Flutter: Run flutter pub add cryptography and flutter pub add http in your
terminal.
```

```
Generate the Key Pair: Write a quick 10-line Arduino sketch using
Ed25519::generatePrivateKey() and Ed25519::derivePublicKey(). Print both to the
serial monitor. Copy these arrays; you will use them for the rest of the
hackathon.
```
